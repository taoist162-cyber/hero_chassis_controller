# hero_chassis_controller

## 项目简介

本项目以 `rm_template` 为模板创建，仓库名称为 `hero_chassis_controller`。

本项目用于完成麦克纳姆轮英雄机器人底盘控制器的开发与考核任务。

## 项目创建说明

- 以 `rm_template` 为模板创建新的 ROS Package。
- 新建仓库名称：`hero_chassis_controller`。
- 已修改 `CMakeLists.txt` 中的项目名称。
- 已修改 `package.xml` 中的功能包名称。
- 已将 README.md 修改为当前项目的说明文档。

## 编译环境

- ROS 版本：ROS Noetic
- 构建工具：catkin-tools
- 开发工具：CLion

## 编译

在工作空间根目录下执行：

```bash
cd ~/chassis_ws
catkin build
```
